### 실행 방법
> 프로젝트 실행 전 `npm install`으로 의존성을 미리 설치해 주세요!
> (iOS의 경우 `cd ios && pod install`도 필요합니다.)

**Metro 서버 실행**
```
npx react-native start
```
**iOS**
```
npx react-native run-ios
```
**Android**
```
npx react-native run-android
```
